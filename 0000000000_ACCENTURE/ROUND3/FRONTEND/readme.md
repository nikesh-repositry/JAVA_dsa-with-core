## Accenture Frontend — Final Practice Checklist

### 🔴 HTML — Must Practice

* `<html>`, `<head>`, `<body>`
* `<div>`, `<span>`
* `<h1>`–`<h6>`, `<p>`
* `<ul>`, `<ol>`, `<li>`
* `<a>`, `<img>`
* `<button>`
* `<form>`, `<label>`
* `<input>` — text, password, email, number, checkbox, radio
* `<select>`, `<option>`, `<textarea>`
* `<table>`, `<tr>`, `<th>`, `<td>`
* `id`, `class`
* `data-*` attributes
* Semantic tags: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`

---

### 🔴 CSS — Must Practice

* Selectors: element, `.class`, `#id`, attribute
* Box Model
* `margin`, `padding`, `border`
* `width`, `height`
* `color`, `background`
* `font-size`, `font-weight`, `text-align`
* `display: block/inline/none/flex/grid`
* **Flexbox**
* Basic **Grid**
* `position`
* `overflow`
* `:hover`, `:focus`, `:active`
* Basic media queries/responsive design
* Basic transitions

---

### 🔴 JavaScript — Highest Priority

* `var`, `let`, `const`
* Data types
* Operators
* `if/else`, `switch`
* `for`, `while`, `for...of`
* Functions
* Arrow functions
* Arrays
* Objects
* Strings
* **Array methods:** `forEach`, `map`, `filter`, `find`, `some`, `includes`, `reduce`
* String methods: `toLowerCase`, `toUpperCase`, `trim`, `includes`, `split`
* Template literals
