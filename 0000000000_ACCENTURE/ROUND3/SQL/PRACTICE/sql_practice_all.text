//
SELECT COUNT(*)
FROM information_schema.tables
WHERE table_schema = DATABASE();
//=in this query 
information_schema ✅ Fixed system database provided by MySQL.
Stores metadata about databases, tables, columns, etc.

tables ✅ Fixed table inside information_schema.
Contains information about all tables in all databases.

table_schema ✅ Fixed column name.
Stores the database name to which a table belongs.
