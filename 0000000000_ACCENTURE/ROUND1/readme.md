# 📘 Accenture Technical MCQ — Preparation Guide

This document provides a **structured roadmap** for preparing Accenture’s Technical MCQ round.  
Focus is on **concept clarity + MCQ practice**, not university-style theory.

---

## 🔥 Priority Topics

| Priority | Topic | What to Study |
|----------|-------|---------------|
| 🔥🔥🔥🔥🔥 | **Pseudocode** | Programming logic, operators, loops, arrays, strings, recursion, bitwise ops, OOP basics, DS |
| 🔥🔥🔥🔥 | **SQL** | SELECT, WHERE, GROUP BY, HAVING, ORDER BY, JOINs, subqueries, aggregate functions, keys, constraints |
| 🔥🔥🔥🔥 | **Operating System** | Processes, threads, scheduling, deadlock, synchronization, memory management, paging, segmentation |
| 🔥🔥🔥🔥 | **CPU & Memory** | CPU architecture, registers, cache, RAM/ROM, memory hierarchy, virtual memory, addressing |
| 🔥🔥🔥 | **Network Security & Cloud** | OSI/TCP-IP, IP, DNS, HTTP/HTTPS, TCP/UDP, firewall, VPN, encryption, authentication, cloud models |
| 🔥🔥🔥 | **Wi-Fi Security** | WEP, WPA, WPA2, WPA3, authentication, encryption, SSID/BSSID, attacks |
| 🔥🔥🔥 | **DevOps** | CI/CD, Git, Docker, Jenkins, Kubernetes basics, version control, monitoring |
| 🔥🔥 | **OOPs** | Class/object, inheritance, polymorphism, abstraction, encapsulation, interface, overloading/overriding |
| 🔥🔥 | **MS Office & Applications** | Word, Excel, PowerPoint, Outlook, shortcuts, formulas, basic computer applications |

---

## 1. 🔥 Pseudocode — Highest Priority

### Study:
- Variables, data types, operators  
- if/else, nested conditions  
- for, while, nested loops  
- Functions, return values  
- Arrays: traversal, searching, sorting, manipulation  
- Strings: traversal, comparison, character ops  
- Bitwise operators: `&`, `|`, `^`, `~`, `<<`, `>>`  
- Increment/decrement, operator precedence  
- Recursion basics  
- Basic DS + OOP logic  
- Output prediction

### Practice:
- ~150–200 pseudocode/output questions  
- Focus on **bitwise + logic-heavy pseudocode** (recent candidate reports)

---

## 2. 🔥 SQL

### Must Know:
- SELECT, WHERE, ORDER BY, GROUP BY, HAVING, DISTINCT  
- Functions: COUNT(), SUM(), AVG(), MIN(), MAX()  
- Joins: INNER, LEFT, RIGHT, FULL, SELF  
- Keys: Primary, Foreign, Candidate, Unique  
- Constraints: NOT NULL, NULL  
- Subqueries  
- DELETE vs TRUNCATE vs DROP  
- Normalization basics  
- Aggregate functions

⚡ **Extremely important:** Joins + Subqueries

---

## 3. 🔥 Operating System

### Cover:
- Processes: states, PCB, context switching  
- Threads: process vs thread, multithreading  
- CPU Scheduling: FCFS, SJF, SRTF, Round Robin, Priority  
- Deadlock: 4 conditions, prevention, avoidance, detection, Banker’s algorithm  
- Memory: paging, segmentation, virtual memory, page fault, fragmentation, swapping  
- Synchronization: race condition, critical section, semaphore, mutex

---

## 4. 🔥 CPU + Memory

### CPU:
- ALU, Control Unit, Registers, Program Counter, Instruction Register  
- CPU cycle: Fetch → Decode → Execute  
- Clock speed, cores, multicore processors  

### Memory:
- Hierarchy: Registers → Cache → RAM → Secondary Storage  
- Cache: hit/miss, L1/L2/L3  
- RAM: SRAM vs DRAM  
- ROM, Virtual memory, Addressing, Fragmentation

---

## 5. 🔥 Network Security + Cloud

### Networking:
- LAN, MAN, WAN, PAN  
- OSI/TCP-IP models  
- IP (IPv4/IPv6), MAC, DNS, DHCP  
- Protocols: HTTP, HTTPS, FTP, TCP, UDP  

### Security:
- Firewall, VPN, Encryption/Decryption  
- Authentication, Authorization, Digital signature  
- SSL/TLS, Malware, Phishing, Spoofing, DoS/DDoS, MITM, IDS/IPS  

### Cloud:
- Service models: IaaS, PaaS, SaaS  
- Deployment: Public, Private, Hybrid  
- Virtualization, VM, Cloud storage, scalability, elasticity, availability

---

## 6. 🔥 Wi-Fi Security

- WLAN, Access Point, SSID, BSSID, Router basics  
- IEEE 802.11 basics  
- Security protocols: WEP → WPA → WPA2 → WPA3  
- Attacks: Evil Twin, Rogue AP, Deauthentication, Eavesdropping, Packet sniffing, Brute-force

---

## 7. 🔥 DevOps

- DevOps basics: CI, CD, Continuous Deployment/Delivery  
- Version control: Git (repo, commit, branch, merge, PR)  
- Docker: container, image, Dockerfile, container vs VM  
- Jenkins: CI/CD pipeline (build, test, deploy)  
- Kubernetes basics: cluster, node, pod, deployment, service  
- Monitoring, logging, automated testing

---

## 8. 🔥 OOPs

- Class, Object, Constructor  
- Encapsulation, Inheritance, Polymorphism, Abstraction  
- Interface, Abstract class  
- Method overloading vs overriding  
- Access modifiers, Static, Final  
- Compile-time vs Runtime polymorphism

---

## 9. 🔥 MS Office & Applications

### Word:
- Formatting, tables, find/replace, headers/footers, page setup, shortcuts  

### Excel:
- Functions: SUM, AVERAGE, COUNT, COUNTA, MAX, MIN, IF, COUNTIF, SUMIF, VLOOKUP/XLOOKUP  
- Rows/columns, cell references, absolute vs relative  
- Sorting, filtering, charts  

### PowerPoint:
- Slides, transitions, animations, presentation modes  

### Outlook:
- Email basics: CC, BCC, attachments, reply/forward, calendar basics  

### Common Applications:
- File extensions, computer terminology, browser basics, command prompt

## ⚠️ Exam Strategy

- **Time per question:** ~60 seconds  
- **Approach:**  
  1. Learn concept  
  2. Solve MCQs  
  3. Analyze mistakes  
  4. Revise weak points  
  5. Attempt timed mock (45Q / 45min)
