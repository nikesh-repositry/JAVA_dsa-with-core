# **2. TOPIC PRIORITIES & FOCUS AREAS**

### **[TIER 1 — ABSOLUTE PRIORITY] (70% of prep time)**

- **Arrays:** Traversal, min/max, second largest, rotation, zero movement, partitioning, prefix sums.
- **Strings:** Reversal, palindrome, character frequency, anagrams, parsing, delimiter inputs.
- **Hashing:** Frequency count, duplicate checks, unique values, first non-repeating element.
- **Two Pointers:** Target sum in sorted arrays, pair/triplet problems, merging, partitioning.
- **Subarrays & Prefix Sum:** Contiguous sum equal to K, Kadane's algorithm, zero sum subarrays.

### **[TIER 2 — SECONDARY PRIORITY]**

- **Searching:** Binary search, lower/upper bounds, rotated sorted array search, peak element.
- **Sorting:** Dutch National Flag (0/1/2 sorting), Merge/Quick sort concepts, frequency sorting.
- **Sliding Window:** Fixed window of size K, variable window for longest substring/subarray.
- **Matrix (2D Array):** Row/col traversal, boundary/spiral traversal, matrix rotation, diagonal sums.

### **[TIER 3 — TERTIARY PRIORITY]**

- **Basic Stack:** Balanced parentheses, stack implementation, reverse using stack, next greater element.
- **Basic Queue:** Queue implementation, circular queue, reverse queue.
- **Basic Linked List:** Traversal, insertion, deletion, reverse, middle node, cycle detection.
- **Basic Math:** Primes, Fibonacci, Armstrong, GCD/LCM, digit manipulation.

> **Priority decision:** Stack, Queue, and Linked List are **not as important as Arrays, Strings, Hashing, Two Pointers, Subarrays, Searching, Sorting, and Sliding Window** for this 20-day plan. However, they should **not be skipped**. Basic questions can still appear in coding tests, pseudocode, or technical interviews. Therefore, this plan adds only the **highest-value basic patterns** instead of spending several days on advanced linked-list or stack/queue problems.

- **Basic Math:** Primes, Fibonacci, Armstrong, GCD/LCM, digit manipulation.
- **Stack / Queue / Linked List:** Balanced parentheses, next greater element, reverse list, cycle detection.

### **[SKIP FOR NOW]**

- Advanced DP, Graphs, Segment Trees, Tries, Backtracking, Heavy Competitive Programming.

# **3. CORE PATTERNS & STRATEGY**

### **Pattern Recognition Rules**

- **Frequency / Unique / Duplicates** -> **[Use HashMap / HashSet / Frequency Array]**
- **Sorted Array + Pair/Target Sum** -> **[Use Two Pointers]**
- **Contiguous Subarray + Sum K / Max Sum** -> **[Use Kadane / Prefix Sum / Sliding Window]**
- **Sorted Array + Search / Rotated** -> **[Use Binary Search]**
- **Window of size K / Substring** -> **[Use Sliding Window]**
- **0s, 1s, 2s / Partitioning** -> **[Use Two Pointer / Dutch National Flag]**

### **Exam & Practice Strategy**

- **Time Allocation:** 10 mins to understand -> 15-20 mins to write -> 5 mins to debug/test edge cases.
- **Spaced Repetition (`1 -> 3 -> 7 -> FINAL`):** Re-solve every problem on Day 1, Day 3, Day 7, and Day 20.
- **Critical Edge Cases to Test:** Empty input, single element, negative numbers, zeros, duplicate values, sorted/reverse sorted inputs.
- **Primary Language:** Use **Java** (or your main preferred language) consistently. Focus on algorithmic logic rather than language switching.
