# <span style="color:#0070C0;">2. TOPIC PRIORITIES & FOCUS AREAS</span>

### <mark style="background-color:#FFCDD2; color:#B71C1C; font-weight:bold;">TIER 1 — ABSOLUTE PRIORITY (70% of prep time)</mark>
- <span style="color:#D32F2F; font-weight:bold;">Arrays:</span> Traversal, min/max, second largest, rotation, zero movement, partitioning, prefix sums.
- <span style="color:#D32F2F; font-weight:bold;">Strings:</span> Reversal, palindrome, character frequency, anagrams, parsing, delimiter inputs.
- <span style="color:#D32F2F; font-weight:bold;">Hashing:</span> Frequency count, duplicate checks, unique values, first non-repeating element.
- <span style="color:#D32F2F; font-weight:bold;">Two Pointers:</span> Target sum in sorted arrays, pair/triplet problems, merging, partitioning.
- <span style="color:#D32F2F; font-weight:bold;">Subarrays & Prefix Sum:</span> Contiguous sum equal to K, Kadane's algorithm, zero sum subarrays.

### <mark style="background-color:#FFE0B2; color:#E65100; font-weight:bold;">TIER 2 — SECONDARY PRIORITY</mark>
- <span style="color:#E65100; font-weight:bold;">Searching:</span> Binary search, lower/upper bounds, rotated sorted array search, peak element.
- <span style="color:#E65100; font-weight:bold;">Sorting:</span> Dutch National Flag (0/1/2 sorting), Merge/Quick sort concepts, frequency sorting.
- <span style="color:#E65100; font-weight:bold;">Sliding Window:</span> Fixed window of size K, variable window for longest substring/subarray.
- <span style="color:#E65100; font-weight:bold;">Matrix (2D Array):</span> Row/col traversal, boundary/spiral traversal, matrix rotation, diagonal sums.

### <mark style="background-color:#FFF9C4; color:#F57F17; font-weight:bold;">TIER 3 — TERTIARY PRIORITY</mark>
- <span style="color:#F57F17; font-weight:bold;">Basic Math:</span> Primes, Fibonacci, Armstrong, GCD/LCM, digit manipulation.
- <span style="color:#F57F17; font-weight:bold;">Stack / Queue / Linked List:</span> Balanced parentheses, next greater element, reverse list, cycle detection.

### <mark style="background-color:#E0E0E0; color:#424242; font-weight:bold;">SKIP FOR NOW</mark>
- Advanced DP, Graphs, Segment Trees, Tries, Backtracking, Heavy Competitive Programming.

# <span style="color:#0070C0;">3. CORE PATTERNS & STRATEGY</span>

### **Pattern Recognition Rules**
- **Frequency / Unique / Duplicates** -> <mark style="background-color:#E1BEE7; color:#4A148C; font-weight:bold;">[Use HashMap / HashSet / Frequency Array]</mark>
- **Sorted Array + Pair/Target Sum** -> <mark style="background-color:#C8E6C9; color:#1B5E20; font-weight:bold;">[Use Two Pointers]</mark>
- **Contiguous Subarray + Sum K / Max Sum** -> <mark style="background-color:#F8BBD0; color:#880E4F; font-weight:bold;">[Use Kadane / Prefix Sum / Sliding Window]</mark>
- **Sorted Array + Search / Rotated** -> <mark style="background-color:#B2DFDB; color:#004D40; font-weight:bold;">[Use Binary Search]</mark>
- **Window of size K / Substring** -> <mark style="background-color:#D1C4E9; color:#311B92; font-weight:bold;">[Use Sliding Window]</mark>
- **0s, 1s, 2s / Partitioning** -> <mark style="background-color:#FFCCBC; color:#BF360C; font-weight:bold;">[Use Two Pointer / Dutch National Flag]</mark>
