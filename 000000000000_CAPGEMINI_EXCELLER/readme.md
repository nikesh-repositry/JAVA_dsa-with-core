# **3. CORE PATTERNS & STRATEGY**[cite: 2]

### **Pattern Recognition Rules**[cite: 2]
- **Frequency / Unique / Duplicates** -> **[Use HashMap / HashSet / Frequency Array]**[cite: 2]
- **Sorted Array + Pair/Target Sum** -> **[Use Two Pointers]**[cite: 2]
- **Contiguous Subarray + Sum K / Max Sum** -> **[Use Kadane / Prefix Sum / Sliding Window]**[cite: 2]
- **Sorted Array + Search / Rotated** -> **[Use Binary Search]**[cite: 2]
- **Window of size K / Substring** -> **[Use Sliding Window]**[cite: 2]
- **0s, 1s, 2s / Partitioning** -> **[Use Two Pointer / Dutch National Flag]**[cite: 2]

### **Exam & Practice Strategy**[cite: 2]
- **Time Allocation:** 10 mins to understand -> 15-20 mins to write -> 5 mins to debug/test edge cases.[cite: 2]
- **Spaced Repetition (`1 -> 3 -> 7 -> FINAL`):** Re-solve every problem on Day 1, Day 3, Day 7, and Day 20.[cite: 2]
- **Critical Edge Cases to Test:** Empty input, single element, negative numbers, zeros, duplicate values, sorted/reverse sorted inputs.[cite: 2]
- **Primary Language:** Use **Java** (or your main preferred language) consistently.[cite: 2] Focus on algorithmic logic rather than language switching.[cite: 2]
